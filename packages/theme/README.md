# @foundation/theme

Light/dark/system theme and density integration. Project branding maps through Foundation theme contracts.

0.12 keeps legacy `primaryColor`, `borderRadius`, and `fontFamily` and adds broader Ant Design `token` / `components` overrides plus Foundation shell `layout` geometry tokens.

## Install

```bash
pnpm add @foundation/theme
```

Use only exports from the package root; deep imports are unsupported. See the repository architecture and release documentation for compatibility policy.
