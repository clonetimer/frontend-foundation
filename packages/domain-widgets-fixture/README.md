# @example/domain-widgets

A retained, domain-neutral component fixture for Frontend Foundation 0.20. It is intentionally outside the `@foundation/*` Runtime Kernel and demonstrates how a project-owned package can supply custom Widgets/Blocks plus `foundation.registry.json` metadata.

The actual React components are rendered by Storybook. The Visual Designer consumes only Registry metadata and renders safe authoring placeholders/containers. This fixture is not a Foundation product package and must remain private.
