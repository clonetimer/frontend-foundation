# Secondary Domain SDK validation package

This package is deliberately **not** a workspace product package and is not published with Frontend Foundation.

It is independently authored from the retained `@example/domain-widgets` fixture to verify that the Domain Component SDK vocabulary is not overfit to one component family.

It covers:

- select/number/boolean properties;
- string/number/boolean bindings;
- an event with no value payload;
- a boolean-valued event;
- a child-accepting block;
- built ESM and declaration admission;
- `npm pack` content admission.
