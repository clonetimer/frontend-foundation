# P4 · Remote DataTable 删除结果不确定状态专项

基线：main `aa039f01a95dca9638c28a9becdc64adb1be272e`。本轮范围为 Studio 远程数据表格与其在独立 React ZIP 中的源码镜像，不修改 Foundation 0.21.0 冻结内核或服务端协议。

## 问题与边界

原版单条删除在 HTTP 503/超时后只显示“不确定”，仍可重新发送同一 DELETE。批量删除虽然在本批次遇到不确定结果就中断剩余请求，但刷新、清空选择、重新选择之后仍可能启动新批次。这不满足跨操作的防重复要求。

新增组件实例级的 **uncertain-delete lock**：单条不确定删除或批次出现任何不确定记录后，暂停所有删除请求；锁定不因列表刷新、跨页、清空选择而消失；保留批量处理统计与跳过记录提醒。页面显式列出不确定记录 ID，并提供二次确认的“已核对服务端，解除删除锁定”。它只记录用户人工确认，**不代表自动完成服务器核对**。解除后清除旧选择并重新刷新数据，避免自动重试旧记录。锁定通过 ref 同步阻止重复调用，状态同时控制单条及批量按钮。未锁定时原有“单条成功/冲突/失败”、“批量部分成功/失败/冲突/不确定/未执行”分类保持不变。

## 验收范围

- 源码镜像：必须与 `tooling/scripts/sync-studio-widget-export.mjs --check` 输出完全相同。
- 单条合成 503：显示结果不确定与锁定提示；重复点击 / 重新选择 / 刷新均不得再次发送 DELETE；明确核对后才可解除锁定。
- 批量合成响应：首条成功、第二条 503、第三条未执行；不得继续发送第三条；批量统计和锁定持久；不得将“成功”推断成客户端本地行消失。
- Linux 与 Windows Studio 生产 Chromium、独立导出 React ZIP 构建、Stable Gate、提交精确 HEAD 证据。
- 真实业务鉴权、版本 CAS、服务器幂等键、跨标签页共享锁、人工读屏验收：NOT RUN，不能因合成网络测试成功而宣布满足正式生产业务需求。

风险说明：关闭页面或重新载入组件会重置内存态锁。因此本改动降低**同一页面会话**内的重复操作风险，不是跨会话或跨设备的全局幂等机制。
