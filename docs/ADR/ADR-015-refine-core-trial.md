# ADR-015: Refine Core trial is headless and gated

Status: Trial approved with constraints.

Evaluate `@refinedev/core` for Data Provider, Auth Provider and Access Control Provider capabilities.

Do not adopt `@refinedev/antd` while it targets Ant Design 5. Do not adopt `@refinedev/react-router` while it targets React Router 7. Foundation keeps its React Router 8 integration during the Core trial.
