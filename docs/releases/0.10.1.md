# Frontend Foundation 0.10.1

Status: **Stable-Ready RC**

## Summary

0.10.1 is a release-readiness hardening release. It does not add new Runtime Kernel capabilities. It closes the repository-level CI/CD, registry publication, immutable promotion, Nginx runtime smoke, packed-consumer and upstream-admission governance needed before Stable promotion.

Key changes:

- GitHub Actions for CI, security, Storybook Pages, candidate publication, registry smoke and Stable dist-tag promotion;
- `pnpm github:verify` included in offline governance gates;
- two-stage registry lifecycle: immutable `candidate` publication → clean registry smoke → `latest` dist-tag promotion;
- `pnpm release:promote` using dist-tags rather than republishing the same version;
- automated real Nginx HTTP smoke via `pnpm deploy:smoke`;
- offline packed-consumer mode that still consumes the exact Foundation `.tgz` bytes under test;
- Contract Adapter admission policy/audit remains independent and Candidate-only;
- release preflight now rejects release notes that still contain `TODO` placeholders.

## Compatibility

- Runtime Kernel source: **byte-for-byte unchanged from 0.10.0**;
- Public Runtime/Capability API snapshot: unchanged and verified;
- project migration: **none required** for existing 0.10.0 `contract=none` applications;
- optional OpenAPI Contract Adapter: remains Candidate/opt-in and is not promoted to Stable by this release.

See `docs/KERNEL_COMPATIBILITY_0_10_1.md`.

These cannot be honestly marked green until executed against the actual external services:

- [ ] Candidate packages actually published to the selected private registry;
- [ ] `registry-smoke.yml` clean install/typecheck/build from that registry succeeds;

Follow `docs/STABLE_PROMOTION.md`.
