# Frontend Foundation 0.15.0

Status: Candidate

## Summary

0.15 adds a structured Action / Binding model on top of 0.14 Visual Composition. Project Blueprint pages can declare typed local state and named Actions; governed Widget properties bind to state and governed Widget events connect to Actions. The Project Compiler validates the interaction graph and emits ordinary React `useState` and callbacks.

## Added

- page-local `string` / `number` / `boolean` state declarations;
- Widget `bindings` with Registry-declared property/type contracts;
- semantic Widget events: `button.press`, `input.change`, `select.change`;
- named Action sequences with `set`, `toggle`, `increment`, `reset` steps;
- event-value and state-value sources for `set` with static type validation;
- controlled `InputWidget` / `SelectWidget` props and governed Widget callbacks;
- machine-readable event/binding capabilities in the Composition Registry;
- Mission Console example exercising state, binding and action compilation;
- Action/Binding tests plus Project Compiler integration coverage.

## Safety boundary

- no arbitrary JavaScript/expression/action strings are accepted in Blueprint;
- event values are typed and may only flow to compatible page state;
- layouts cannot declare events/bindings;
- controlled `value` bindings cannot be combined with `defaultValue`;
- network/resource/async/navigation/permission actions are deferred to explicit future adapters.

## Compatibility

- 0.14 Visual Composition-only Blueprints remain source-compatible after their Foundation minor version is upgraded to 0.15.x;
- planned Runtime delta is limited to additive callback/controlled-value props in `@foundation/ui` Visual Composition widgets;
- Project Blueprint remains build-time only and generated page source remains `scaffold-once`.
