# Frontend Foundation 0.21.0 · 完整源码快照（非正式 Stable）

此 GitHub Release 是 **Frontend Foundation 源码预发布快照**，不代表 npm Registry `latest` 晋升，也不代表 Pattern Atlas Studio 编辑器正式 Stable。

## 源码制品

- `frontend-foundation-0.21.0-source-<commit12>.zip`：按精确 Git 提交打包的**仓库完整受版本控制源码**（含源码、示例、测试、工作流、文档）。
- `frontend-foundation-0.21.0-source-<commit12>.tar.gz`：等价源码的 tar.gz 版本。
- `SHA256SUMS`：以上源码包和元数据的 SHA-256。
- `SOURCE-METADATA.txt`：精确来源提交、pnpm lockfile SHA-256、生成工作流等。
- GitHub 自动显示的 `Source code (zip)` / `Source code (tar.gz)` 也对应相同的 Release Git 标签。

源码快照由 `git archive` 生成，因此**不包含**未提交的 `node_modules`、本机数据库、缓存、外部私有数据、未跟踪文件或构建产生的 `dist`。如需运行，请使用 Node 22/24 与仓库锁定的 pnpm 11.7.0，并运行：

```bash
corepack enable
corepack pnpm install --frozen-lockfile
corepack pnpm check
```

`pnpm dev:studio` 可运行现有 Studio 前端；源码包**不附带**实际业务后端、用户凭据或生产模型/数据库。

## 验证与状态

发布工作流必须先验证来源提交是当前 `main` 的精确 HEAD，且该 SHA 的 `Static gates`、Node22、Node24、Windows 离线验收、Security CodeQL、Storybook build/deploy 均完成成功；再生成归档并逐包自检 SHA-256。发布时记录精确 SHA，不使用浮动分支指针，也不修改已有 Release。

Foundation npm 0.21.0：**Stable-Ready，尚未完成目标 Registry candidate → latest 的外部验收晋升**。Studio 编辑器 1.0.0-rc.1：另有独立草稿候选 Release，仍待人工和真实业务后端验收。参阅 [功能冻结与交付清单](../FEATURE_FREEZE_DELIVERY_HANDOFF_20261020.md)、[Foundation 0.21.0 验收](../STABLE_ACCEPTANCE_0_21.md) 和 [Studio 待办 Issue #29](https://github.com/clonetimer/frontend-foundation/issues/29)。
