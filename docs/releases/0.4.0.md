# Frontend Foundation 0.4.0

Status: Candidate

## Summary

0.4.0 is a productization release. It intentionally does not add a new UI capability family.

It adds:

- publishable `@foundation/create-app`;
- `foundation-doctor` project compatibility checks;
- network-independent release preflight;
- dependency-topological release planning;
- version synchronization tooling;
- tarball-first publication workflow with dry-run by default;
- private-registry and air-gapped distribution guidance;
- Stable release gates and upgrade policy.

## Compatibility

Kernel public contracts are unchanged from the 0.3 line. Productization tooling is outside the Kernel graph.

Applications upgrading from 0.3.x should move all Foundation packages to 0.4.x together. Use `foundation-doctor --target 0.4.0` before and after the package update.

## Migration

No Kernel API migration is required by this release. The main change is distribution policy: external applications should consume published semver packages/tarballs and must not use workspace protocols or deep imports.
