# Frontend Foundation 0.16.0

Status: Candidate

## Summary

- Added build-time HTTP Data Source and Operation declarations to Project Blueprint visual pages.
- Added governed request query/body state references, async pending/error lifecycle state, and JSON/text response-to-state assignments.
- Added `invoke` and internal `navigate` Action steps.
- Compiler emits ordinary `useApiTransport`, async functions and `useNavigate`; no runtime Blueprint interpreter or arbitrary JavaScript strings were added.
- Added machine-readable Data/Operation capabilities to the Composition Registry.
- Added static validation and ownership-regeneration tests for unsafe URLs, GET bodies, lifecycle state types, unknown operations and human-edited scaffolds.

## Compatibility

- Kernel public contract: unchanged from the reviewed 0.15 Runtime Kernel source baseline.
- Migration requirement: additive Project Blueprint fields; existing 0.15 Blueprints remain valid after aligning Foundation/tooling to 0.16.x.
- HTTP Operations require a Profile carrying the `api-transport` capability.
