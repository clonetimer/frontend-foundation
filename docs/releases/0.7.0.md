# Frontend Foundation 0.7.0

Status: Goal-First Candidate

## Summary

- Reframes implementation governance from “OSS-first” to **goal-first, OSS-evaluated**.
- Adds a capability registry that separates project requirements from the current implementation package.
- Adds three domain-neutral `create-foundation-app` profiles: `minimal`, `management`, and `data-workbench`.
- Extends `foundation-doctor` to detect profile dependency drift.
- Extends release preflight and consumer testing so all profiles are generated and validated.
- Keeps ProComponents and Refine Core as isolated shadow candidates; neither is promoted into production dependencies.

## Compatibility

- Kernel public contract: unchanged from 0.6/0.5 runtime contracts.
- Existing applications: no source migration required solely because of 0.7.
- Existing projects without `package.json.foundation.profile`: supported; profiles are an opt-in creation/governance aid.
- OSS migration requirement: none. Current `data/forms/security/ui` implementations remain the production baseline.
