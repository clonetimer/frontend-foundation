Status: OSS Convergence Candidate

## Summary

- Changes implementation policy from build-first to OSS-first.
- Adds shadow PoCs for Ant Design ProComponents and Refine Core without introducing either into production package dependencies.

- Adds OSS upstream snapshot, migration matrix, policy, baseline metrics and verification tooling.

## Compatibility

- Kernel public contract: unchanged from the 0.5 baseline during shadow evaluation.
- Migration requirement: none for existing consumers; OSS experiments are outside the production workspace.
- Production dependency graph: no ProComponents or Refine dependency is promoted in this candidate.
