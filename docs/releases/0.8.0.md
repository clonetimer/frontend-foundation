# Frontend Foundation 0.8.0

Status: Candidate

## Summary

0.8.0 adds **Delivery Readiness** without changing Runtime Kernel contracts.

- Adds a deployment dimension independent from application Profiles.
- `create-foundation-app --deployment nginx` generates production Nginx/Docker assets.
- Nginx delivery supports BrowserRouter fallback, immutable Vite asset caching, mutable runtime configuration, health checks, gzip, and optional same-origin `/api` reverse proxy.
- `foundation-doctor` validates declared deployment assets.
- Adds deployment validation tooling and release-preflight coverage.
- Explicitly keeps Redis outside Frontend Foundation; Redis is evaluated only for concrete server-side shared-state requirements.

## Compatibility

- Kernel public contract: unchanged.
- Existing generated projects: no migration required.
- `foundation.deployment` metadata is additive; older projects without it remain valid.
- Default create-app deployment remains `none`.
