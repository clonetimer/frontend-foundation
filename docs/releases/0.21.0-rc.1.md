# Frontend Foundation 0.21.0-rc.1

Status: Release Candidate

## Summary

- Freezes the 0.20 feature surface and shifts the mainline to release convergence rather than new Blueprint/Designer capability.
- Adds a second independently authored Domain Component SDK package under `tooling/fixtures/secondary-domain-widgets` to test that the SDK vocabulary is not overfit to the retained workspace fixture.
- Extends Designer Chromium smoke so the same assertions can run against an externally hosted Designer through `DESIGNER_SMOKE_URL`, avoiding environments that block local browser navigation.
- Removes the stale Designer `0.19 Beta` UI badge and aligns active examples/tests with the RC version line.
- Keeps the Frontend Foundation Runtime Kernel contract unchanged from the reviewed 0.20 baseline.

## Compatibility

- Kernel public contract: unchanged from 0.20.0; no Runtime source/API migration is introduced by this RC convergence release.
- Project Blueprint: schemaVersion remains `1`; no new Blueprint fields or DSL semantics are added.
- Domain Component SDK / Custom Registry: schemaVersion remains `1`; the second package is validation evidence, not a new Registry feature.
- Migration requirement: Candidate users can run `foundation-upgrade . --target 0.21.0-rc.1 --write` to align Foundation package ranges/config metadata. The upgrader does not rewrite application source.
- Production users should not move to the RC line until their normal candidate/registry process accepts the exact immutable package version.
