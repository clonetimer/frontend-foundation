# Frontend Foundation 0.12.0 — UI Composition Candidate

## Scope

0.12 is the first intentional Runtime Kernel evolution after the frozen 0.10.1 Stable baseline. It converts the hard-coded application shell into an additive Shell Contract and adds reusable UI composition primitives/tooling metadata.

## Added

- `ApplicationDefinition.shell`.
- Built-in `sidebar`, `top-nav`, `workspace`, and `bare` shell presets.
- Project-owned custom shell contract with routed content passed as children.
- Theme `token`, `components`, and Foundation layout geometry overrides while preserving legacy brand fields.
- `PanelBlock`, `MetricBlock`, `MetricGrid`.
- `DashboardPattern`, `MasterDetailPattern`, `SplitPanePattern`, `WorkspacePattern`.
- `create-foundation-app --shell ...` and `--list-shells`.
- `foundation-generate --list-composition`.
- New module patterns: `dashboard`, `master-detail`, `workspace`.
- Doctor validation for configured shell metadata.

## Preserved

- Existing applications without `shell` use the prior sidebar experience.
- `ApplicationModule[]`, route metadata, permission boundaries, `ApiTransport`, AppError and Resource Blueprint v1 contracts remain intact.
- Resource Blueprint remains build-time source generation and does not become a runtime low-code schema.

## Migration

No mandatory source migration is expected for 0.11 applications. To opt into a new shell, add for example:

```ts
shell: { preset: 'workspace' }
```

Generated 0.12 projects record the shell in `foundation.config.json` and `package.json` Foundation metadata.
