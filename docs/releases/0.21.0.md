# Frontend Foundation 0.21.0

Status: Stable-Ready (immutable final semver; external promotion evidence delegated)

## Summary

- Promotes the frozen 0.21 RC convergence line to final semver `0.21.0` without adding Blueprint, Designer, Domain SDK or Runtime capability.
- Keeps the 0.20 -> 0.21 owned Runtime Kernel byte-for-byte unchanged and retains the same public API snapshot.
- Retains two independently authored Domain Component SDK admission fixtures as evidence that Custom Registry/SDK contracts are not overfit to a single component family.
- Retains external-URL Designer browser smoke support for user-run unrestricted browser/visual acceptance.
- Adds explicit RC-to-Stable upgrade regression proving prerelease Foundation ranges/metadata can move to `0.21.0` without rewriting application source.
- Freezes the release object for immutable Candidate publication and later dist-tag promotion; no new product feature is part of this version transition.

## Compatibility

- Kernel public contract: unchanged from 0.20.0 and 0.21.0-rc.1.
- Project Blueprint: `schemaVersion: 1`, no new fields or semantics.
- Custom Registry / Domain Component SDK: `schemaVersion: 1`, no new fields or semantics.
- Migration: run `foundation-upgrade . --target 0.21.0` for a dry-run and add `--write` after review. The upgrader updates Foundation dependency ranges and Foundation metadata; it does not rewrite application source.
- RC projects using `^0.21.0-rc.1` should move to `^0.21.0` before Stable consumption.
