# Frontend Foundation 0.14.0

Status: Candidate

## Summary

- Added Visual Composition v1: recursive build-time layout/widget trees in Project Blueprint pages.
- Added governed Layout Registry (`stack`, `grid`, `split`, `tabs`) and Widget Registry (`panel`, `text`, `button`, `input`, `select`, `metric`, `placeholder`).
- Added `@foundation/ui` visual layout/widget primitives and serializable catalog entries.
- Project Compiler emits ordinary editable TSX with stable `foundation-node:<id>` trace markers; there is no runtime Blueprint renderer.
- Added strict property whitelists, unique node IDs, depth/node limits, split/tab invariants, and rejection of executable event-code properties.
- Extended the published Mission Console Blueprint example and Storybook source coverage.
- Preserved Pattern generation as the high-level preset path; explicit `page.composition` is additive.

## Compatibility

- Kernel public contract: additive `@foundation/ui` exports; other Runtime Kernel packages are unchanged by Visual Composition.
- Migration requirement: 0.13 Project Blueprints migrate to the 0.14 Foundation/tooling minor line; existing pages do not require `composition` and keep Pattern behavior.
- Runtime boundary: Project/Visual Blueprints remain build-time inputs only.
