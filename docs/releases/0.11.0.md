# Frontend Foundation 0.11.0

Status: Candidate

## Summary

- Adds Resource Blueprint v1 as a build-time productivity input for conventional management resources.
- Adds `foundation-generate resource <resource.json>` to generate editable list/detail/edit React modules, typed request helpers and module metadata.
- Resource modules remain ordinary project source and keep HTTP/error/trace behavior on Foundation `ApiTransport`/`AppError` contracts.
- Doctor validates Resource Blueprint SHA-256 drift and required generated files.
- Management profile now explicitly declares `error-model` and `api-transport` capabilities so generated resource code only imports declared public contracts.
- Resource generation is included in the packed consumer release gate.

## Compatibility

- Kernel public contract: unchanged from 0.10.1.
- Runtime Kernel source: expected zero changes; verified during final candidate validation.
- Migration requirement: existing 0.10.1 projects do not need migration. Newly generated `management` projects receive explicit `@foundation/core` and `@foundation/api` dependencies because the profile now declares the corresponding capabilities.
- Resource Blueprint is opt-in and has no browser runtime cost until generated project code imports the resulting module.
