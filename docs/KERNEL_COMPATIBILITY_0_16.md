# Kernel Compatibility — 0.16

0.16 Data / Operation Model is implemented in `@foundation/create-app` tooling and Project Blueprint compilation. No Runtime Kernel `packages/*/src` source change is required relative to the reviewed 0.15 baseline.

Generated operation code reuses existing public contracts:

- `@foundation/api` `useApiTransport()` / `ApiTransport.fetch()`;
- React local state generated by the Project Compiler;
- React Router `useNavigate()` already present in generated applications.

Therefore the owned Runtime Kernel SHA-256 baseline remains the reviewed 0.15 baseline. 0.16 must not reset that baseline merely because workspace package versions changed.
