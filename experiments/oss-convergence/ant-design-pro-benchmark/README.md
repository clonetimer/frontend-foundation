# Ant Design Pro v6 Benchmark

No source is vendored or forked here.

Benchmark the upstream application as a reference implementation for:
- project startup effort;
- layout/menu/breadcrumb behavior;
- ProTable/ProForm productivity;
- OpenAPI workflow;
- theme and responsive behavior;
- test/build toolchain;
- bundle and cold-start characteristics.

Do not use benchmark results to justify copying the whole repository. The architectural question is which upstream packages/practices should be consumed by the package-based Foundation.

Upstream: https://github.com/ant-design/ant-design-pro
