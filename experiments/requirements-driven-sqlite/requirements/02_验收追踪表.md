# 实验验收与需求追踪

## 证据等级

- `AUTO_PASS`：在当前执行环境中，确实运行了 Python 单测或本地 HTTP 合同测试，检查真实 SQLite 数据/HTTP 结果。
- `STATIC_PASS`：Python 语法编译、JavaScript 语法校验通过，不代表浏览器功能通过。
- `BLOCKED`：已尝试但环境阻断，不能填“已通过”。
- `NOT_TESTED`：需在实际用户电脑/实际业务文件运行，不能凭模拟值充当通过。
